# Login e cadastro ZeroBet
Novo layout preto e rosa com banner do tigre, mensagens distintas de boas-vindas, campos em uma coluna e adaptação desktop. Sem opção de Google na interface. Recuperação de senha, persistência da sessão e código de afiliado preservados. Cadastro pede senha de 8 caracteres; login continua aceitando senhas antigas. Confirmação de idade e termos reunida em um checkbox obrigatório.
Firebase preservado. Não exige SQL ou alteração de banco.
Validação: TypeScript e build Vite. Teste visual com navegador não executado: download do Chromium falhou. Login/cadastro reais não testados no Firebase remoto.
Executar npm install e npm run dev. Abrir http://localhost:3000.
